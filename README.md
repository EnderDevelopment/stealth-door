# StealthDoor

StealthDoor is a Minecraft plugin designed to enhance the gameplay experience by allowing players to create stealth doors. These doors are disguised as solid blocks, providing a unique way to hide passages in your builds. The plugin tracks standard door placement, links camouflage blocks to the door, toggles visibility on interaction, and automatically closes the door after a set time.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to enable the plugin.

## Use

1. Place a standard door in the world.
2. Place solid blocks directly in front of the door to camouflage it.
3. Interact with the camouflage blocks to toggle the door's visibility.
4. The door will automatically close after 5 seconds.
